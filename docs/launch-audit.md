## 公開前に残る判断・確認

| 項目 | 現状 | 必要な対応 |
|---|---|---|
| 販売者表示 | 屋号・住所・メールはあるが、販売主体/氏名は本人が保留 | 事実を確定して表示方針を決める。任意の人名を当てはめない |
| 袋代 | 人が見積もりで案内する方針だが金額ルール未定 | 追加請求するなら条件・金額等の表示を整理。表示単価がある状態で、個別案内だけで十分とは断定しない |
| 銀行手数料 | 農園負担は確定、負担方法は未定 | 顧客が実際に手続きできる案内を決める。勝手に差し引き振込を案内しない |
| 支払い期限 | 一律の日数は未採用 | 注文確定案内での期限とサイト上の説明をそろえる |
| 返品・取消 | 返品条件は暫定採用済み、確定後キャンセル等は未確定 | 実際の運用と表示を最終確認 |
| 栽培・保管の説明 | 一部は旧HPの紹介を継承 | 現行工程と一致することを本人確認 |
| 公開・切り戻し | 手順書と事前チェックは準備、実操作は未実施 | 最終バックアップ・変更対象一覧・本人の公開承認後に実施 |
