# バックアップ復号用秘密鍵の別保管

## 現在の状態

2026-10-20時点では、ageの復号用秘密鍵は作業PCのアクセス制限した非公開領域にのみ存在する。PC外への別保管は未実施。秘密鍵の実体・内容をこの資料、Git、チャット、バックアップ保存先のDriveへ転記しない。

## 保管方法

利用中のパスワード管理アプリの保護されたメモ、または暗号化・アクセス保護したPC外の媒体を候補とする。ユーザーが指定した保管先だけへ保存する。PC内の別フォルダーへコピーするだけではPC故障への対策にならない。

パスワード管理アプリでは「三田村農園HP バックアップ復号用秘密鍵」と分かる名前で保管する。アプリの復旧方法と、PCが使えないときに別の端末からアクセスできることも確認する。

USB等を使う場合は、指定された媒体を確認してからコピーする。紛失に備えて媒体や鍵ファイルを暗号化する場合、解除用のパスワードを同じ媒体だけに保存しない。解除方法を失うと鍵を取り出せない。

## 保存後の確認

1. 指定先から秘密鍵を読み戻せることを確認する。画面・ログ・チャットへ鍵の内容を出さない。
2. ファイルとして読み戻せる場合は元ファイルとのハッシュ一致を確認する。
3. 読み戻した鍵で暗号化バックアップを復号し、内容のハッシュを確認する。可能な限り平文をディスクへ保存せず検証する。
4. 秘密値を含めず、保管先の種類、確認日、読み戻し・復号確認の結果を重要設定一覧に記録する。保存しただけで復旧確認済みと扱わない。

## 運用上の注意

この秘密鍵はGoogleのログインパスワード、OAuth認証情報、LaravelのAPP_KEYとは別のもの。復旧時には、まずage秘密鍵で保存セットを復号し、セット内の設定を使ってアプリの暗号化データを扱う。

秘密鍵を紛失しても、Google DriveやXserverから再発行して既存バックアップを復号することはできない。鍵を変更する場合は、以前の鍵で暗号化した保存セットが残る間は以前の鍵も保持する。
