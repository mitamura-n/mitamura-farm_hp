# 注文受付後のメールひな形

更新：2026-11-04。担当者が内容を確認して手動送信するための資料。カード払いの案内は、受付開始後に使用する。

## 使う前の確認

- 通常注文では60kgでも袋代を請求しない。大口等の例外は農園が個別判断し、必要な費用は注文確定前に明細と合計を案内して了承を得る。袋分け希望だけで自動加算しない。

- フォーム直後の自動受付メールとは別に、以下の4段階で対応する。
- ［ ］を実際の情報へ置き換え、該当しない行は削除する。未確定の金額・在庫・発送日を確約しない。
- 年産・商品別の数量・精米前重量・精米度合い・袋分け、税込商品代・精米料・送料・手数料の合計を照合する。精米後の重量は減るため、精米前重量と明示する。
- 代引きは税込330円を最終合計に含め、二重加算しない。支払い方法や配送先で金額が変われば、変更後の見積もりに了承を得てから注文確定する。
- 銀行振込・郵便振替・代引きの決済手数料はすべてお客様負担。振込手数料をご請求金額から差し引く案内はしない。
- 口座情報は農園が確認した正式な情報を送信時に入力し、このGit資料に実値を保存しない。銀行振込・郵便振替の支払い期限は注文確定のご案内から7日以内。難しい場合は連絡を受けて相談する。代引きにはこの期限を適用しない。
- カード払いの受付開始までは、見積もりの支払い方法からカード払いとその手数料案内を外す。
- カード払いは、見積もりへの了承を得て注文を確定した後、次の順で案内する。決済手数料は農園負担。
  1. Squareで請求書を作成し、宛先と請求額を照合する。支払期限を送信予定日の7日後に設定して送信する。
  2. Squareで送信状況を確認し、実際の送信日と請求書に表示された期限が合っているか照合する。
  3. 請求書番号と確認した期限を転記して、注文確定メールを送る。
- カード情報はSquareの決済画面で入力していただく。期限経過後に未払いで注文を取り消す場合は、Squareの未払い請求書も取り消し、お客様に知らせる。
- 住所・電話番号等の返信は受付番号と照合して安全に管理する。顧客情報をGitや作業記録に転記しない。
