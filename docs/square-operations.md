# Square請求書：導入準備と日常の手順

2026-11-04更新。Squareの審査承認は10月30日の本人報告で確認。追加する支払方法はSquare請求書によるカード払い。銀行振込・郵便振替・代引きは継続する。オンラインのカード受付、売上振込先の認証状態、下書きプレビューは管理画面での確認待ち。実請求・決済・返金は未実施で、HPの「準備中」表示は維持。PayPayは将来検討。

## 開始前に確認する画面

1. [Square データ](https://app.squareup.com/dashboard)に農園のアカウントでログインし、請求書の作成画面でオンラインのカード払いを選べるか確認する。
2. 売上の振込先が登録・認証済みか確認する。口座番号・認証コードは作業記録に転記しない。
3. 送信せずに下書きで、農園名、カード払いの表示、商品代・精米料・送料・合計が分かることを確認する。テストの顧客情報や仮の請求額を本番で送信しない。
4. 支払い期限は請求書で個別に案内する。発送は決済確認後に手配し、発送予定は注文確定時に案内する。カード手数料は顧客に上乗せしない案。農園の実際の手数料条件はSquare管理画面で確認する。

## 請求書の下書きに入れる内容

- 件名：三田村農園｜ご注文のお支払い（受付番号：［MF-…］）
- 明細：［商品名・数量／玄米基準重量］［税込商品代］、［精米料］、［送料］
- 支払期限：［注文確定時に案内した日付］。通貨：JPY。合計は了承済みの金額と一致させる。
- メモ：お見積もりにご了承いただきありがとうございます。こちらの請求書からカードでお支払いください。お支払いを確認後、発送の手配をいたします。ご不明な点は三田村農園までご連絡ください。

## HP・メールの公開用文案（設定確認後に反映）

- 支払い案内・特商法：クレジットカードをご希望の場合は、見積もりにご了承いただいた後、Square請求書をメールでお送りします。請求書に記載の期限までに、Squareの支払い画面からお支払いください。
- 発送案内：クレジットカードの場合は決済確認後に発送の手配を行います。発送予定は注文確定時にご案内します。
- プライバシー案内：カード払いをご希望の場合は、請求書の送付と決済の確認にSquareを利用します。請求先の氏名・メールアドレスと、請求明細など必要な情報をSquareに登録します。カード情報はお客様がSquareの支払い画面に直接入力します。農園のフォームやメールには記載しないでください。
- 注文確定メール：［受付番号］のお支払いには、別途お送りするSquare請求書をご利用ください。お支払い合計：［税込合計］円。期限：［年月日］。お支払いを確認後、発送の手配をいたします。

## 受付番号で照合する

サイトの受付番号MF-…を、金額案内メールとSquare請求書の参照情報またはメモに記載する。Squareの請求書番号・決済IDとは別物として照合する。

問い合わせ管理の「注文になった」は内部の結果分類であり、入金確認や発送指示ではない。現状、サイトに決済の自動同期・注文台帳・発送管理機能はない。

## 金額の案内から発送まで

1. 問い合わせと在庫を確認。年産・商品・口数・玄米基準重量・精米度合い・袋分けを確認する。
2. 梱包込み重量・地域・箱サイズ・同梱から送料を確認。商品代金・精米料・送料・その他の確定済み費用を明細化する。
3. `order-mail-templates.md` の金額案内を送り、総額・支払方法・発送条件への了承を得る。現時点のフォーム送信だけでは注文確定としない。
4. カード希望の場合、Square請求書を注文ごとに作成。宛先、受付番号、商品明細、送料、合計、通貨JPYを照合。商品価格は税込なので消費税を二重加算しない。食品と送料等の税区分は会計上の取り扱いを確認して設定し、一律税率を仮設定しない。
5. Squareのプレビューで顧客に見える内容を確認。利用可能なカードブランドと、有効化済みのカード支払い設定を確認。カード以外の追加決済を勝手に案内しない。
6. 決済リンクの送信は一方の経路に統一する（Squareから送信するか、リンクを農園メールへ添えるか）。同じ注文で請求書を二重作成しない。初回は本人の確認後に送信。
7. Square管理画面で対象の請求書・金額・支払い完了・返金の有無を照合。顧客のスクリーンショットや完了ページだけで入金扱いにしない。銀行口座への売上振込とカード決済成功は別の状態。
8. 決済確認後に発送予定を案内。カードの発送起算日を「決済確認後」とする案は公開前にユーザー確認する（既存の銀行振込・郵便振替・代引きの起算日は確定済み）。
9. 配送先・宛名・必要な連絡先を業務に必要な範囲で確認し、発送後に配送業者・追跡番号を案内。追跡番号を公開ページへ載せない。

## 重複・変更・返金

- 支払い済みで請求書を再送・再作成しない。未払いでも請求書と受付番号を先に照合する。
- 金額変更は支払い状態を確認してから行う。旧リンクが使えるまま新しい請求を作らず、Squareの正式な取消・修正手順を確認する。
- 返金は内容・金額・送料の扱いを確認し、明示承認を得てSquareの元の取引から実行する。返金手数料や所要日数は申込後の条件を確認し、未確認の数値を約束しない。
- 支払い不明・保留・エラーは未入金として個別確認する。サイトの通知メール送信成功は決済成功ではない。
- カード番号・有効期限・セキュリティコードをフォーム、メール、管理メモへ保存しない。

## 登録後の確認項目

- 利用承認、登録口座の認証、通知先メール、二要素認証、操作担当者のアクセス。
- 請求書フリープランの実際の設定、カード手数料、売上の入金サイクル、返金・取消条件。
- 顧客側の表示（農園名・連絡先・請求明細・支払方法）、スマホでの支払い導線。
- テスト方法はSquareの公式案内に従う。架空の売上や自分のカードによる自己決済を検証の前提にしない。本番請求・課金は今回行わない。
- 利用可能と確認できてからHPに「カード決済対応」と掲載し、プライバシー案内の外部サービスにもSquareを追加する。

## 未確定として残す項目

- 特商法ページの販売業者氏名は公開済み。Squareの登録・顧客画面での事業者表示は別途確認する。
- 銀行振込・郵便振替の既存期限は7日。カードの期限は請求書で個別案内する案。
- カードの具体的な決済手数料条件と、取消・返金画面の確認。
- 銀行振込の振込手数料はお客様負担。カード手数料の扱いとは区別する。
- 郵便振替の払込手数料はお客様負担、代引き手数料は税込330円をお客様負担として確認済み。
