# スマホ幅での表示・操作確認

2026年10月15日、ブラウザーの表示幅を320・375・390・430pxへ変更して確認。

## 修正

- メイン見出しが一文字だけ次の行へ落ちていたため、スマホ用文字サイズを可変にし、字間を縮小。
- セクション見出しも小型画面に合わせてサイズ調整。
- 物語の導入文はスマホだけ意味のまとまりで改行。
- メニューと商品選択ボタンは高さ44px以上を確保。
- select・textareaの文字サイズを16pxへ変更。

## 実施した確認

- トップ・ロゴ・田植え写真・商品カード・物語セクション・フォーム・確認ダイアログを実際に表示。
- 320・375・390・430pxでページ全体の横スクロールなしをDOM寸法で確認。
- メニュー開閉と商品リンクへの移動後にメニューが閉じることを確認。
- 玄米の選択から注文相談フォームへ移動し、商品とご用件が反映されることを確認。
- 確認ダイアログの表示と入力画面への復帰を確認。送信は行わない。

実機のiPhone・Androidでの確認ではなく、PCブラウザー上の画面幅による検証。モバイルOS固有のキーボードやSafariの挙動は未検証。
