# 問い合わせの管理

管理者で https://preview.mitamurafarm.com/admin/inquiries を開く。

- 新しい受付から20件ずつ表示し、対応状況で絞り込める。
- 受付番号から氏名・返信先・商品明細・相談内容・通知状態を確認する。
- 対応状況は「未対応」「対応中」「案内済み」「対応完了」。農園内の記録で、メール送信・見積提示・注文確定の自動処理は行わない。
- 通知は「開発ログのみ・未送信」「処理待ち」「送信失敗」「送信済み」を区別。送信済みも受信箱への到達保証ではない。
- 古い画面からの上書きを拒否。失敗したら最新表示を確認して編集し直す。
- 管理者以外には閲覧・更新を許可しない。応答はno-store。
- 元の問い合わせ内容や送信状態は、対応状況の更新で変更しない。本文はHTMLとして実行せず文字として表示。

メールの再送、返信履歴の同期、自由メモ、CSV出力、削除、見積・注文・発送の管理、担当者別履歴は未実装。初回はメールと受付番号を使って対応する想定。正式な保存期間と削除運用は公開前に決める。
