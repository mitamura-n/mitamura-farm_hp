# 購入につながるサイトへの改善

2026年10月15日。ユーザー方針：デザインの雰囲気を維持しながら、売れる・買いたくなるサイトを重視。

## 第一段階の実施

- トップの主ボタンを商品選択へ変更。農園の物語へのリンクは残す。
- 商品欄の冒頭に、白米・玄米・分づき米の選び方を追加。
- 注文後精米、精米料と送料を含む金額の案内、了承後の確定を明記。
- 商品ごとに送料別を案内し、希望入力へ進むボタンの意味を明確化。
- 数量・精米方法・都道府県の入力欄を追加。確認画面にも反映。
- 白米選択→精米方法反映→10kg・福井県入力→確認ダイアログの表示をブラウザーで検証。390px幅で横はみ出しなし。
- フォームはプレビューのみ。保存・送信・決済は行わない。

## 複数商品の入力改善

単一商品選択と自由記入の数量欄は整合しないため、商品＋数値数量（kg）を行単位で追加・削除するUIへ変更。分づき米だけ精米度合いを表示。確認画面でも商品別の明細を表示する。白米10kg＋米粉1kgの入力、確認画面への反映、分づき欄の表示切替、行削除をブラウザーで確認済み。390px幅で横はみ出しなし。Laravelの既存テスト2件も成功。

数量は希望として受け付けるもので、0.1kg単位での販売を保証しない。実際の販売単位・最低量を確定後、商品別の入力制約へ反映する。

- 炊き上がりのごはん・実際の商品袋・食卓の写真。現在のお米カードの図形は仮表示であり、実物写真へ置き換えると商品の具体像を伝えやすい。
- 味・食感の説明は生産者の実感や根拠を確認して追加。評判・販売実績・希少性を創作しない。
- 税込表示、送料、精米料、在庫、発送日数を確定し購入前の不明点を減らす。
- 問い合わせ受付のDB保存・通知・受付番号。公開後、訪問から商品選択・入力・受付・確定までのどこで離脱するかを適切な計測設計で確認する。

これらの変更が売上を増やすかは未検証。現段階では選びやすさと金額確認までの導線を改善する仮説として扱う。
