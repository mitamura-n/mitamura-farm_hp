# 商品マスタ・管理画面

作成日：2026-10-15。ローカル開発環境に実装済み。公開サーバーへの導入は未実施。

## 初回の管理者作成

プロジェクトのフォルダーでPowerShellを開き、次を実行します。

```powershell
./dev.ps1 artisan -TaskArgs farm:admin
```

管理者メールアドレス、12文字以上のパスワード、確認用パスワードを対話入力します。パスワードは画面に表示されません。チャットへパスワードを送らないでください。既存アカウントの上書き・権限変更は行いません。

ログイン：http://127.0.0.1:8000/admin/login

商品管理：http://127.0.0.1:8000/admin/products

管理者だけが編集できます。公開登録画面はありません。ログインは5回/分の制限があります。パスワード再発行・管理者削除画面は今回の対象外です。本番の管理者は本番環境で別途作成します。

## 管理項目

現在の商品5種類について、1口の重量（整数kg）、規格の表示名、数量上限（口）、1口の参考価格、受付中／受付停止を編集します。商品追加・削除・名称変更・複数規格の併売は対象外です。価格・数量・受付状態が商品案内とフォームに反映されます。開いたままのページは再読み込みしてください。

- お米：玄米重量10kg分で初期設定。白米・分づき米は精米前の重量です。
- 米粉：1kg入り1袋で初期設定。
- 米ぬか：2026-10-19に1kg入り1袋・1,000円（税込）を確認し受付開始。
- 数量上限：未設定。空欄でもシステム上は同一商品合計999口までです。
- 価格：従来の暫定価格を移行。精米料・送料は含まず、商品価格は税込と確認済みです。価格空欄はお問い合わせ表示です。

規格の表示名と重量は必ず一致させてください。例：重量5kgなら表示名も「玄米重量5kg分」。異なる規格を同時に販売する場合は、別途規格管理に拡張します。

## 問い合わせフォームへの反映

数量は口数を整数で入力し、規格の重量を掛けたkgを送信します。米10kg分×2口なら玄米重量20kgです。ブラウザーとサーバーの両方でチェックし、サーバーは同じ商品を複数行に分けた数量も合算します。受付停止中の商品は指定できません。

受付時点の規格・重量・数量表示を暗号化した問い合わせ商品欄に保存し、後のマスタ変更で過去の内容が変わらないようにしています。既存受付の内容は変更しません。

編集時に別の画面で保存済みの場合は上書きを拒否します。入力エラー時には再表示された現在値を確認して編集し直してください。

## DB導入

通常の artisan migrate で商品マスタと管理者フラグを追加します。既存の問い合わせを削除する操作はありません。migrate:fresh は既存データを削除するため、運用DBでは使わないでください。
