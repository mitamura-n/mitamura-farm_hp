三田村農園・運用者向けアプリ

Mitamura Farm Backup

三田村農園のウェブサイトを障害から復旧するため、暗号化したバックアップを農園管理のGoogleドライブへ保存する専用ツールです。一般のお客様が利用・登録するサービスではありません。

Googleドライブとの連携

連携にはGoogleの認可を利用します。要求する権限は drive.file で、このアプリで作成・使用する特定のファイルを対象に参照・作成・編集・削除できる範囲です。現在の転送処理は、アプリが作成した専用フォルダーへ暗号化済みファイルを保存し、転送結果を確認します。

バックアップは転送前に暗号化します。復号用秘密鍵はGoogleドライブおよび転送用サーバーへ保存しません。

このアプリのプライバシーポリシー

利用条件

本アプリは、三田村農園が認めた運用担当者が農園のバックアップ業務に使用する専用ツールです。一般のお客様向けの利用登録は受け付けていません。連携するGoogleアカウントは農園管理のものに限り、必要な権限を確認したうえで認可します。Googleサービスの利用にはGoogleの利用規約等が適用されます。

認証情報と復号用秘密鍵を第三者へ開示せず、復旧試験と保存状態の確認を行って運用します。連携を停止する場合は、Googleアカウントで認可を取り消し、不要となった認証情報・バックアップを運用担当者が整理します。
